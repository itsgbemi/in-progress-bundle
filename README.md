# my-office

An intuitive, high-performance, and feature-rich website editor and content management system designed for professionals, creators, and businesses. Streamline webpage creation, configure nested folder paths, manage custom CMS collections, and monitor your pages using live visual previews.

---

## 🚀 Key Product Capabilities

### 🛠️ Interactive Website Editor & Builder
- **Rich Visual Section Management**: Design webpages block-by-block with an integrated editor supporting flexible component blocks.
- **Instant Snapshots & Live Thumbnails**: View real-time visual mockups of your designs enwrapped in modern 16:9 aspect ratio containers.
- **Nested Folder Hierarchies**: Seamlessly structure site routing and path organizations like `/blog` or `/products/new` with full active breadcrumbs.

### 📦 Robust CMS (Content Management System)
- **Dynamic Content Collections**: Define schemas for your pages, blogs, portfolios, or directories using flexible custom fields.
- **Structured Data Binding**: Seamlessly couple content databases to your frontend views.
- **Status & Lifecycle Tracking**: Control page visibility via statuses like Draft, Scheduled, Archived, or Published.

### 🔒 Privacy & Optimization Options
- **SEO & Indexing Control**: Easily toggle search engine crawling (`index` vs. `no-index`) on a per-page basis.
- **Password Protection**: Protect sensitive drafts or member-only sections with a password guard.
- **Multi-select & Bulk Operations**: Group-select listed pages using circular select indicators and execute actions like bulk deletions effortlessly.
