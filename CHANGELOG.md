# Changelog

All notable changes to the **my-office** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.1] - 2026-09-20

### Added
- **Circular Multi-Select Toggle**: Added intuitive select-all and clear-selection controls to the dropdown.
- **Card-Enclosed Thumbnail Frames**: Added elegant outer padding (`p-3.5 pt-2.5`) around webpage snapshot previews with soft inner drop shadows and bordered frames.

### Changed
- **16:9 Thumbnail Aspect Ratio**: Updated visual webpage cards to display thumbnail previews in a standard `16/9` widescreen aspect ratio layout.
- **Compact Card Borders**: Reduced the outer card borders from `rounded-2xl` to `rounded-xl`, and inner thumbnail frames to `rounded-lg` for tighter corner nesting.
- **Cleaner Card Layout**: Removed the separator border line dividing webpage info headers from their thumbnail previews for a seamless unified design.
- **Streamlined Select Dropdown**: Replaced checkboxes with circle icons (`Circle`) on the main multi-select trigger and cleaned up the dropdown actions.

---

## [1.0.0] - 2026-09-15

### Added
- **Initial Core Release**: Fully functional local website editor and workspace.
- **Folder Path Builder**: Supports deep nested page directory hierarchies and parent navigation.
- **Custom CMS Schema**: Configurable static site metadata fields (tags, custom scripts, passwords, index controls).
- **Interactive Section Builder**: Block-by-block layout visual workspace with multiple preset sections.
- **Search and Sorting Filters**: Live text lookup and workspace list/card grid switching modes.
